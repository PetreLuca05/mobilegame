# M7: NPCs

Sign-off: `d000819`, followed by the M7b pass. Rules and measurements: [PERF.md](PERF.md), `CLAUDE.md` (NPCs).

## Deferred (accepted, not built)

- Staff hurrying when a patrol is overdue.
- A doctor pinned to an exam room while it is occupied.
- Doorway path cost. An NPC waits at a doorway instead, the lower index going first.
- Translucent glasses. Elders wear opaque lighter lenses.
- Debug archetype count sliders.
- Slot name on tap. The Slots overlay labels slots within 3 m of the player.

## Determinism

The NPC sim depends only on the seed and the tick: no viewer, frame rate or thread count. Reactions to the local player (side-step, greeting) and idle touches are computed where the NPC is drawn. Density Low draws half of the NPCs and simulates all of them, so every client has the same people.

A client joining a room replays from the seed to the room's tick. Tick 0 is the earliest `npc_epoch` in Presence. The replay runs at most 1 ms per frame, so the time to catch up grows with the room's age. Continue replays to the saved tick the same way.
